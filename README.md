# 🐱 Cat Invoice — سیستم صدور و مدیریت فاکتور

یک اپلیکیشن وب کامل برای صدور، مدیریت و پیگیری فاکتورها با رابط کاربری فارسی (RTL).  
طراحی شده برای کسب‌وکارهای کوچک و متوسط ایرانی که نیاز به صدور فاکتور حرفه‌ای با قابلیت کار آفلاین دارند.

---

## ✨ امکانات

### فاکتور
- صدور فاکتور با شماره‌گذاری خودکار (`INV-2026-000001`)
- ویرایش، حذف، کپی فاکتور
- تخفیف درصدی و مبلغی
- محاسبه خودکار مالیات (سطح اقلام + سطح فاکتور)
- تاریخ فاکتور و تاریخ سررسید
- وضعیت پرداخت (پرداخت شده / پرداخت نشده)
- چاپ مستقیم و خروجی PDF
- اقلام با واحد، تعداد، قیمت واحد و دوره تکرار (ساعتی، روزانه، هفتگی، ماهانه، سالانه)

### مشتریان
- مدیریت مشتریان (نام، تلفن، آدرس، کد ملی)
- **هوش مصنوعی تطابق مشتری** — تشخیص خودکار مشتریان تکراری و نام‌های مشابه هنگام تایپ
- جستجوی سریع مشتری در فرم فاکتور
- حذف گروهی مشتریان

### محصولات
- مدیریت کالاها با واحد و دوره تکرار
- **تاریخچه قیمت** — هر تغییر قیمت ثبت می‌شود، قیمت‌های قبلی حفظ می‌شوند
- محاسبه خودکار میزان فروش و درآمد هر کالا
- جستجوی سریع محصول در فرم فاکتور

### حساب‌های بانکی
- ذخیره اطلاعات بانکی (نام بانک، شماره کارت، شماره شبا، صاحب حساب)
- حساب پیش‌فرض
- نمایش اطلاعات بانکی روی فاکتور

### گزارش‌ها
- گزارش فروش بر اساس مشتری و بازه زمانی
- خروجی اکسل (Excel)
- خروجی PDF با طراحی حرفه‌ای فارسی
- نمودار و آمار داشبورد

### پروفایل فروشنده
- نام کسب‌وکار، شناسه ملی، آدرس، تلفن، ایمیل
- آپلود لوگو
- مدیریت واحدهای سفارشی

## 🔐 امنیت و احراز هویت

### سیستم OTP (رمز یکبارمصرف)
- ارسال کد ۵ رقمی از طریق ایمیل (SMTP)
- اعتبارسنجی کد تا ۵ دقیقه
- حداکثر ۵ تلاش اشتباه
- هش‌کردن کد قبل از ذخیره در دیتابیس (SHA-256)

### مراحل احراز هویت
1. **ورود**: نام کاربری + رمز عبور → ارسال OTP به ایمیل → تأیید کد
2. **تغییر رمز**: رمز فعلی + OTP ایمیل → رمز جدید
3. **تأیید ایمیل**: هنگام ثبت‌نام، ایمیل باید تأیید شود

### حفاظت اضافی
- **CAPTCHA ریاضی** — بعد از ۴ بار تلاش ناموفق، کد امنیتی نمایش داده می‌شود
- **مسدودسازی ایمیل‌های یکبارمصرف** — لیست ۵۰+ دامین موقت مسدود شده
- ** اعتبارسنجی سختگیرانه ایمیل** — جلوگیری از ثبت‌نام با ایمیل‌های جعلی
- **Throttle** — محدودیت نرخ درخواست‌ها روی API
- **Multi-tenant** — داده‌های هر کاربر کاملاً جدا از بقیه است

## 📱 PWA — Progressive Web App

این اپلیکیشن یک PWA کامل است و روی موبایل و دسکتاپ قابل نصب می‌باشد.

### قابلیت‌های PWA
- **نصب روی دستگاه** — از مرورگر قابل نصب است (آیکون دسکتاپ / صفحه اصلی موبایل)
- **بنر نصب** — فقط یک بار نمایش داده می‌شود؛ پس از بستن، آیکون 📲 دائمی در سایدبار باقی می‌ماند
- **کار آفلاین** — صفحات اصلی بدون اینترنت قابل دسترسی هستند
- **پایگاه داده محلی (IndexedDB)** — فاکتورها و داده‌ها در مرورگر ذخیره می‌شوند
- **همگام‌سازی خودکار** — هنگام وصل شدن به اینترنت، داده‌های آفلاین با سرور هماهنگ می‌شوند
- **کلید عدم تکرار (Idempotency Key)** — جلوگیری از ثبت فاکتور تکراری در حالت آفلاین
- **نسخه‌بندی داده** — هر فاکتور شماره نسخه دارد تا هماهنگ‌سازی دقیق باشد
- **اعلان‌رسانی (Push Notification)** — آماده برای دریافت نوتیفیکیشن

### ارتباط PWA و دیتابیس
```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────┐
│   مرورگر        │     │     سرور         │     │ PostgreSQL  │
│  (IndexedDB)    │ ←→  │    Django        │ ←→  │  Database   │
│                 │     │                  │     │             │
│ • فاکتور آفلاین │     │ • اعتبارسنجی     │     │ • داده اصلی │
│ • sync-engine   │     │ • تطابق مشتری    │     │ • تاریخچه   │
│ • offline-db    │     │ • OTP ایمیل      │     │ • فاکتورها  │
└─────────────────┘     └──────────────────┘     └─────────────┘
```

### فایل‌های PWA
| فایل | توضیح |
|------|-------|
| `static/sw.js` | Service Worker — کش صفحات و مدیریت آفلاین |
| `static/manifest.json` | تنظیمات PWA — نام، آیکون، رنگ، مسیرها |
| `static/js/pwa-manager.js` | ثبت SW، مدیریت نصب، وضعیت آفلاین |
| `static/js/sync-engine.js` | موتور هماهنگ‌سازی آفلاین ↔ سرور |
| `static/js/offline-db.js` | پایگاه داده محلی (IndexedDB) |

## 📧 سیستم ایمیل (OTP)

### پیکربندی
از Gmail SMTP برای ارسال کدهای OTP استفاده می‌شود:

```
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=True
EMAIL_HOST_USER=your-email@gmail.com
EMAIL_HOST_PASSWORD=your-app-password
```

### مراحل دریافت کد
1. کاربر نام کاربری و رمز را وارد می‌کند
2. سرور یک کد ۵ رقمی تصادفی تولید می‌کند
3. کد با SHA-256 هش شده و در دیتابیس ذخیره می‌شود
4. کد از طریق Gmail SMTP به ایمیل کاربر ارسال می‌شود
5. کاربر کد را وارد می‌کند — سرور هش ورودی را با هش ذخیره‌شده مقایسه می‌کند
6. کد فقط ۵ دقیقه معتبر است و حداکثر ۵ بار قابل تلاش است

### نکته برای Gmail
برای استفاده از Gmail SMTP باید:
1. **تأیید هویت دو مرحله‌ای** را در حساب گوگل فعال کنید
2. از بخش **App Passwords** یک رمز اپلیکیشن بسازید
3. آن رمز ۱۶ رقمی را در `EMAIL_HOST_PASSWORD` قرار دهید

## 🗄️ دیتابیس (PostgreSQL)

### مدل‌ها
| مدل | توضیح |
|-----|-------|
| `User` | کاربر سفارشی (Custom User) با فیلدهای اضافی |
| `OTPCode` | کدهای یکبارمصرف با هش و تاریخ انقضا |
| `SellerProfile` | پروفایل فروشنده/کسب‌وکار |
| `Customer` | اطلاعات مشتریان (متعلق به هر کاربر) |
| `Product` | کالاها با واحد و دوره تکرار |
| `PriceHistory` | تاریخچه قیمت محصولات |
| `Invoice` | فاکتورها با Snapshot اطلاعات مشتری/فروشنده |
| `InvoiceItem` | اقلام فاکتور با قیمت Snapshot |
| `InvoiceNumberSequence` | شماره‌گذاری خودکار فاکتورها |
| `Bank` | لیست بانک‌ها |
| `BankAccount` | حساب‌های بانکی کاربران |

### ویژگی‌های مهم دیتابیس
- **Snapshot** — اطلاعات مشتری و فروشنده هنگام صدور فاکتور کپی می‌شود. اگر مشتری بعداً اطلاعاتش را تغییر دهد، فاکتورهای قبلی تغییر نمی‌کنند
- **تاریخچه قیمت** — هر قیمت جدید به عنوان رکورد جداگانه ثبت می‌شود (هیچ قیمتی پاک نمی‌شود)
- **شماره‌گذاری خودکار** — فاکتورها با فرمت `INV-سال-شماره` شماره‌گذاری می‌شوند
- **Multi-tenant** — تمام داده‌ها با `user` ForeignKey جداسازی شده‌اند
- **JSONField** — واحدهای سفارشی در پروفایل فروشنده به صورت JSON ذخیره می‌شوند

## 🛠️ راه‌اندازی

### روش ۱: Docker (پیشنهادی)

```bash
# ۱. مخزن را کلون کنید
git clone https://github.com/Nemokia/Cat_Automatic_invoice.git
cd Cat_Automatic_invoice

# ۲. فایل محیطی را بسازید
cp .env.example .env
# فایل .env را ویرایش کنید (مخصوصاً SECRET_KEY و EMAIL)

# ۳. اجرا کنید
docker compose up -d --build

# ۴. سایت در پورت 8000 آماده است
#    http://localhost:8000
```

**حساب مدیر خودکار ساخته می‌شود:**
- نام کاربری: `admin`
- رمز عبور: `admin123`

> ⚠️ حتماً رمز پیش‌فرض را بعد از اولین ورود تغییر دهید.

### روش ۲: نصب محلی

**پیش‌نیازها:**
- Python 3.12+
- PostgreSQL 14+
- pip

```bash
# ۱. مخزن را کلون کنید
git clone https://github.com/Nemokia/Cat_Automatic_invoice.git
cd Cat_Automatic_invoice

# ۲. محیط مجازی بسازید
python -m venv venv
source venv/bin/activate  # لینوکس/مک
# venv\Scripts\activate   # ویندوز

# ۳. وابستگی‌ها را نصب کنید
pip install -r requirements.txt

# ۴. فایل محیطی را بسازید
cp .env.example .env
# DB_HOST=localhost را تنظیم کنید

# ۵. دیتابیس را بسازید
createdb cat_invoice_db
# یا از psql:
# CREATE DATABASE cat_invoice_db OWNER cat_invoice;

# ۶. مایگریشن و اجرا
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver 0.0.0.0:8000
```
